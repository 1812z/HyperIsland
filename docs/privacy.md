# HyperIsland 隐私政策

更新日期：2026 年 9 月 8 日  
生效日期：2026 年 9 月 8 日

欢迎使用 HyperIsland。HyperIsland 是面向 HyperOS 的开源 LSPosed 模块。本政策说明应用会处理哪些信息、处理目的、数据去向以及您可以如何联系我们。请在使用前完整阅读本政策；如果您不同意，请在首次启动提示中选择“退出”。

## 1. 适用范围

本政策适用于 HyperIsland Android 应用、随应用运行的 LSPosed 模块以及由应用主动发送的匿名兼容性统计。您主动配置的第三方 AI 服务、GitHub、LSPosed 等独立服务由相应服务提供者按照其政策处理数据。

## 2. 我们处理的信息

### 2.1 匿名兼容性统计

在您明确同意本政策后，应用会通过 [Aptabase](https://aptabase.com/) 发送 `environment_snapshot` 环境快照，包含：

- HyperIsland 版本名和版本号；
- Android API 等级、Android 版本、设备商品名或型号；
- 完整系统版本 `ro.build.version.incremental`；
- HyperOS 主版本 `ro.mi.os.version.name`；
- SystemUI、SystemUI 插件的版本名和版本号；
- 焦点通知协议版本；
- Xposed 框架名称、版本以及模块是否启用并包含 SystemUI 作用域；
- 首次引导是否尚未完成；
- Aptabase SDK 自动附带的事件时间、临时会话标识、调试版本标记、系统区域/语言、应用版本和设备型号。

临时会话标识由 SDK 随机生成，会随应用进程或会话变化，不是 Android ID、广告 ID 等持久设备标识。Aptabase 服务器会在网络连接过程中接触来源 IP，并据此生成匿名统计标识及国家/地区信息；应用不会把原始 IP 作为自定义事件字段提交。

同一应用版本通常最多每 24 小时发送一次环境快照；应用版本或统计字段结构变化后可能立即发送一次。统计只在 HyperIsland 应用主进程中运行，不会在 SystemUI 或其他 Hook 进程中运行。

### 2.2 本地功能数据

为了提供模块功能，应用可能在设备本地读取或处理：

- 已安装应用和通知渠道，用于选择需要适配或自定义的应用；
- 通知标题、文本、图标和操作，用于在超级岛中渲染通知；
- 已配对或附近蓝牙设备信息，用于用户主动配置的蓝牙白名单；
- 用户设置、模块配置、图片路径以及用户主动创建的备份文件；
- Root、LSPosed、SystemUI 和系统协议状态，用于环境检查和执行用户主动选择的系统操作。

这些信息默认仅在本机用于实现功能，不会作为 Aptabase 统计事件发送。

### 2.3 用户主动启用的第三方功能

如果您主动启用并配置 AI 通知功能，应用会按照您填写的接口地址，将处理通知所需的文本、提示词、模型参数和您提供的 API 密钥发送给该第三方服务。相关数据如何保存和使用由您选择的服务提供者决定。HyperIsland 不会把您的 AI API 密钥发送给 Aptabase。

当您主动检查更新、打开教程、隐私政策或下载页面时，系统浏览器或应用可能访问 GitHub、hyperisland.1812z.top 等对应站点，这些站点可能按照各自政策处理常规网络日志。

## 3. 权限用途

- 网络权限：访问 Aptabase、更新服务、文档页面以及用户配置的 AI 接口；
- 查询应用列表权限：展示和配置应用、通知渠道及兼容性功能；
- 蓝牙权限：读取用户主动配置功能所需的蓝牙设备信息，不将蓝牙扫描用于定位；
- 下载管理相关权限：执行用户主动发起的资源下载；
- Root 与 LSPosed 能力：修改模块配置、检查作用域并执行用户明确触发的系统操作。

拒绝非必要权限可能使对应功能不可用，但不会改变已同意的匿名兼容性统计范围。

## 4. 使用目的

我们仅将上述信息用于：提供和维护模块功能、判断系统兼容性、确定适配优先级、排查版本分布问题、保障服务与项目安全。统计信息不用于广告、用户画像、跨应用跟踪或出售数据。

## 5. 数据共享、存储与跨境传输

匿名兼容性统计发送至 Aptabase 的美国区域并存储在美国，因此会发生跨境传输。Aptabase 是该统计服务的技术提供者。除实现上述功能、遵守法律要求或保护用户与项目安全所必需的情形外，我们不会向其他第三方出售或共享统计数据。

Aptabase 当前开源服务实现对调试事件和正式事件设置不同保留期限；实际云服务保留期限还可能受服务政策与账户设置影响。我们会在实现统计目的所需的期限内保存数据，并可根据合理请求删除可定位的项目统计数据。由于统计不包含持久设备标识，我们通常无法从聚合数据中准确定位某一台设备的历史事件。

## 6. 我们不收集的内容

匿名统计不会收集 Android ID、广告 ID、IMEI、设备序列号、MAC 地址、电话号码、账号、精确位置、联系人、短信、文件内容、通知内容、用户配置、已安装应用列表、蓝牙设备列表或各 Hook 点的运行状态。当前 Aptabase Kotlin SDK 也不会自动上传应用崩溃、异常消息或堆栈。

## 7. 数据安全

我们尽量减少收集字段，使用 HTTPS 传输统计事件，并将统计逻辑限制在应用主进程。任何网络传输或存储都无法保证绝对安全；如果发现安全问题，请通过下方联系方式报告。

## 8. 您的选择与权利

首次启动时，只有勾选“我已仔细阅读并同意上述条款”并点击强调色的“下一步”按钮，才会在本地记录同意状态并启动统计。已完成旧版引导但尚未记录同意的用户，需要在阻断弹窗中点击“同意并继续”；点击“退出”、按返回键或关闭弹窗均不会记录同意，应用会退出。清除应用数据或重新安装后会再次请求同意。

您可以通过系统设置撤销权限、停止使用或卸载应用。对于访问、更正、删除或咨询统计数据的请求，可以通过下方渠道联系我们。由于数据采用匿名聚合方式，部分针对单台设备的数据权利请求可能无法与历史事件建立对应关系。

## 9. 未成年人保护

HyperIsland 面向具备 Android、Root 与 LSPosed 操作能力的用户，不专门面向儿童。未成年人应在监护人指导和同意下使用。

## 10. 政策更新

我们可能随功能、统计字段或服务提供者变化更新本政策。发生重要变化时，应用可能再次请求您的同意。页面顶部会标明最新更新日期。

## 11. 联系我们

如对本政策、数据处理或安全问题有疑问，请通过 [HyperIsland GitHub Issues](https://github.com/1812z/HyperIsland/issues) 联系项目维护者。

您还可以查阅 [Aptabase 隐私政策](https://aptabase.com/legal/privacy) 和 [Aptabase 开源项目](https://github.com/aptabase)。
