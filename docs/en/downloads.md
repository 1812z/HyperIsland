## System Software {#system-software}

If you encounter Super Island display issues, System UI crashes, or screen-recording status problems, try the compatibility packages below. Never install a package intended for a different system version.

::: warning Before installation
- Only install components matching your HyperOS major version, Android version, and device architecture.
- Replacing System UI is risky. Back up the original component and prepare a recovery method first.
- These packages are intended for troubleshooting; do not replace system components when the module already works correctly.
:::
