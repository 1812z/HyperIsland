## 系统软件 {#system-software}

如果使用模块时遇到超级岛显示异常、系统界面崩溃、录屏状态无法上岛等问题，可以尝试安装下方兼容组件。系统组件与系统版本强相关，请勿跨版本混装。

::: warning 安装前必读
- 只安装与你的澎湃 OS 大版本、Android 版本和设备架构匹配的组件。
- 替换系统界面具有风险，操作前请准备可恢复环境并备份原组件。
- 这些资源用于兼容性排查，不建议在模块工作正常时替换系统组件。
:::
