# 配置预设与还原

设置页进入「配置预设」，可以创建本地预设、导入预设，以及应用云端预设。新建和应用时均可通过分类树选择配置范围。

## 应用范围

- 外观等普通分类按选中的分类整体替换，预设未包含的字段恢复默认值。
- 通知配置只替换所选应用的通知与渠道配置；Toast 配置只替换所选应用的 Toast 配置。同应用的另一类型、其他应用不受影响。
- System UI 扩展功能可单独选择，例如蓝牙岛、充电岛、流畅岛，应用某个功能时仅覆盖该功能相关配置。

## 还原配置

点击页面右上角菜单中的「还原配置」，在弹出的分类树中勾选需要恢复的分类，再点击「应用」。点击右侧强调色「取消」按钮可关闭对话框。

还原会清空选中分类的保存值，使其使用默认设置。通知和 Toast 按应用、按类型清空，不会删除其他应用的配置，也不会删除本地预设。

## 应用列表加载

进入页面后会后台准备应用名称与图标，应用列表只加载可见条目，并使用淡入和箭头旋转动画。已经加载的名称与图标缓存会复用，收起列表不会清空缓存。
