# 常见问题

::: details 不显示通知？
- 检查系统界面通知权限是否开启
- 尝试点击测试通知按钮，并检查下面的 FAQ
:::

::: details 测试通知没有效果？
请确认：
1. LSPosed 中模块已启用且作用域正确勾选
2. 已重启作用域内的应用
3. 2个破解焦点通知白名单开关已开启
4. 系统版本为HyperOS3，且LSPosed API为101+
:::

::: details 通知没有显示为超级岛样式？
- 确保应用发出的是**标准安卓通知**，自定义通知样式不受支持
- 检查该应用在手机自身通知设置中是否开启焦点通知权限
- 确认 HyperCeiler 破解焦点通知已正确设置
:::

::: details 通知样式改变，如何恢复？
- 在软件设置内关闭焦点通知
:::

::: details 超级岛光效不起效果？
1. 检查系统是否为安卓 16 的澎湃 OS3
2. 检查是否使用了第三方的系统界面组件
3. 第三方系统可能不受支持
:::

::: details 修改配置后不生效？
- 更新应用后需要重启作用域
- 尝试重启系统界面
:::

::: details 同时出现悬浮通知和焦点通知怎么办？
- 请尝试到系统自身通知设置中，关闭悬浮通知
:::

::: details 通知样式出现错位等问题？
- 请尝试更新系统界面组件版本，或者进一步反馈给开发者
:::

::: danger 出现BUG？
请上传LSPosed日志，并附带复现步骤或者完整视频，虽然大概率不会修 ):
:::

::: details 超级岛挤入、展开或收起动画卡顿，如何采集性能报告？
1. 更新模块后重启系统界面，进入「关于 → 调试工具」，开启调试模式。
2. 进入「超级岛性能分析」，点击「开始采集」，在 60 秒内复现双岛挤入、焦点通知下拉松手或收起动画。
3. 返回性能分析页，点击「停止并查看报告」；自动停止后可点击「刷新状态与报告」。
4. 导出 JSON 报告，并附上复现步骤和所用材质。报告包括主线程 Hook 耗时排行、近期慢调用与动画事件，可用相对时间关联帧延迟。
5. 通过 Hook 管理停用疑似 Hook，重启系统界面后重复相同步骤，对比报告。

采集默认关闭，最长 60 秒，关闭调试模式会立即停止。诊断临时观察 Hook 在停止时卸载，报告仅保存在当前 SystemUI 进程内，不写入配置或配置备份，不记录通知正文。帧样本仅统计采集到的可见超级岛；没有样本不代表没有卡顿。帧间隔和主线程回调迟到不等于 GPU 帧耗时；回调耗时扣除 chain.proceed，但直接嵌套调用可能重叠，异步工作不在计量内，因此排行和时间相关性只能作为定位线索。
:::
