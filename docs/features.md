# 功能介绍

HyperIsland 面向澎湃 OS 3/4，主要用于把普通通知、Toast、下载和录屏状态接入超级岛，并提供外观、展开行为与过滤规则等自定义能力。

## 功能目录

| 功能分类 | 主要能力 | 适合场景 |
|:---|:---|:---|
| [应用与渠道](#应用与渠道) | 按应用启用、Toast 转发、渠道独立配置、批量设置 | 先决定哪些通知可以上岛 |
| [超级岛显示](#超级岛显示) | 模板、布局、图标、展开、滚动、自动消失 | 调整岛内内容与交互方式 |
| [焦点通知](#焦点通知) | 焦点面板、状态栏、锁屏、光效 | 控制通知展开后的系统表现 |
| [外观与材质](#外观与材质) | 高亮色、背景、模糊、玻璃材质 | 统一超级岛的视觉风格 |
| [过滤与场景规则](#过滤与场景规则) | 关键词过滤、勿扰、全屏、横屏处理 | 减少不需要的提醒与打扰 |
| [高级文本表达式](#高级文本表达式) | 占位符、正则提取与替换 | 精简或重组通知文案 |
| [Hook 拓展](#hook-拓展) | 下载管理器、屏幕录制岛 | 增强系统组件的上岛体验 |
| [焦点通知破解](#焦点通知破解) | 移除系统白名单限制 | 让更多应用支持焦点通知 |

::: tip 推荐配置顺序
先在“应用适配”中选择应用，再配置模板与显示样式；最后按需设置过滤规则、外观或高级表达式。
:::

## 应用与渠道

### 应用适配

可为任意应用单独启用超级岛，也可以搜索应用名或包名，并对多个应用批量应用设置。开启“显示系统应用”后，还能配置下载管理器等系统组件。

### Toast 转发

在应用适配页顶部切换至 **Toast** 模式，可按应用处理标准文本 Toast：

- 将 Toast 文本转为焦点通知与超级岛
- 转发后拦截原始 Toast 弹窗，避免重复提示
- 选择是否保留到通知中心、显示大岛图标
- 多选应用后批量应用相同规则

::: info 适用范围
仅支持标准文本 Toast，自定义 Toast 视图不会被拦截。
:::

### 通知渠道

对于 QQ 等包含多个通知渠道的应用，可分别启用和配置即时消息、系统推送等渠道。每个渠道均可使用不同的模板、样式和过滤规则。

## 超级岛显示

### 模板与布局

| 选项 | 作用 |
|:---|:---|
| 通知超级岛 | 将普通通知转换为焦点通知与超级岛 |
| 下载 | 识别文件名与下载进度，并提供下载操作 |
| AI 通知超级岛 | 使用 AI 精简岛左侧与右侧内容 |
| 新图文组件 + 底部文本按钮 | 最多显示两个底部按钮 |
| 封面组件 + 自动换行 | 支持两行焦点通知和底部按钮 |
| 新图文组件 + 右侧文本按钮 | 在右侧显示一个文本按钮 |

### 显示与展开

- **超级岛图标**：自动使用应用图标，或选择自定义图标
- **大岛图标**：控制展开态左侧图标
- **初次展开 / 更新展开**：决定通知首次出现或内容更新时是否自动展开
- **消息滚动**：让较长文本在岛内滚动显示
- **自动消失**：设置超级岛自动隐藏时间
- **窄字体**：切换岛内窄字体；开启后句点可能显示为冒号

## 焦点通知

- **焦点图标**：使用应用图标或自定义图标
- **焦点通知**：关闭后保留超级岛，但把原通知恢复为普通通知
- **状态栏图标**：控制状态栏通知图标
- **锁屏通知复原**：锁屏时恢复普通通知，以使用系统隐私策略
- **外圈光效**：在焦点通知周围显示动态光效

::: warning 注意
关闭焦点通知后，超级岛由系统界面代发。默认配置中的“拦截悬浮通知”会拦截已成功上岛通知的原始悬浮提示，但通知栏中的原始通知仍会保留。
:::

## 外观与材质

### 颜色与背景

- 自定义高亮颜色，支持 HEX 色值
- 从超级岛图标动态提取高亮颜色
- 选择左侧或右侧文本使用高亮色
- 分别设置小岛、大岛和焦点通知背景
- 调整背景透明度与模糊程度

### 岛材质

大岛、小岛和展开态可分别使用默认、高斯模糊、高光玻璃、液态玻璃或柔光玻璃。小岛与展开态可以跟随大岛，也可以独立调整光影、折射、背景、混色和高光参数。

- HyperOS 4 的柔光玻璃复用系统原生 Bionics 材质接口
- HyperOS 3 使用柔光玻璃时会自动回退为高光玻璃
- 自定义背景与玻璃材质互斥
- HDR 高光、液态玻璃采样与陀螺仪光效属于全局设置

## 过滤与场景规则

### 关键词过滤

| 模式 | 行为 |
|:---|:---|
| 黑名单 | 命中任一黑名单关键词时不上岛 |
| 白名单 | 只有命中白名单且未命中黑名单时才上岛 |

同时命中两种列表时，以黑名单为准。

### 勿扰、全屏与横屏

“设置 → 过滤规则”用于按前台应用配置；“设置 → 其他 → 过滤规则”用于设置全局默认行为。系统按 **勿扰 → 全屏 → 横屏** 的顺序匹配，命中第一条可用规则后停止。

| 处理方式 | 命中规则后的表现 |
|:---|:---|
| 默认 | 不额外处理，继续使用默认行为 |
| 回退普通通知 | 不显示超级岛，恢复普通通知 |
| 关闭展开 | 保留小岛，但不自动展开焦点通知 |
| 自动展开通知 | 自动展开焦点通知 |

::: tip 常见用法
游戏或视频全屏时可选择“关闭展开”或“回退普通通知”；横屏时只想保留小岛可选择“关闭展开”。全屏与横屏同时满足时，全屏规则优先。
:::

## 高级文本表达式

“焦点通知高级自定义”和“超级岛高级自定义”支持用表达式重新组织显示文本。表达式长度上限约为 320 个字符。

### 常用变量

| 变量 | 内容 |
|:---|:---|
| `${title}` | 当前标题 |
| `${subtitle}` | 当前副标题或正文 |
| `${subtitle_or_title}` | 副标题为空时使用标题 |
| `${raw_title}` / `${raw_subtitle}` | 原始通知标题与正文 |
| `${pkg}` | 应用包名 |
| `${channel_id}` | 通知渠道 ID |
| `${progress_text}%` | 0–100 的进度文本 |

### 内置函数

| 函数 | 作用 |
|:---|:---|
| `trim(text)` | 去除首尾空白 |
| `regex(text, pattern, group)` | 使用正则提取内容，`group` 默认为 0 |
| `replace(text, pattern, replacement)` | 使用正则替换内容 |

常用示例：

```text
${trim(subtitle_or_title)}
${regex(subtitle, "(id\d+)", 1)}
${pkg} · ${channel_id}
${progress_text}%
```

表达式异常时，先用 `${title}` 等单个变量验证，再逐步加入函数，并检查括号与引号是否成对。

## Hook 拓展

### 下载管理器

拦截 HyperOS 下载管理器通知，以超级岛展示文件名和下载进度，并提供 **暂停、继续、取消** 操作。暂停后还可显示恢复下载通知。

下载上岛默认关闭。请先开启“显示系统应用”，再在应用适配中启用“下载管理程序”，并在 Hook 拓展中开启对应功能。

### 屏幕录制岛

在“设置 → Hook 拓展 → 屏幕录制”中开启后，可用超级岛和独立 Miuix 弹窗代替官方录屏悬浮窗，并支持暂停、继续与结束录制。

- **动态照片**：仅作用于下一次录制，最长 30 秒；封装成功后删除原 MP4，失败时保留
- **立刻录制**：点击通知栏磁贴后跳过确认弹窗，可热加载
- 修改录屏上岛总开关后，需要重启屏幕录制应用

不同系统版本需要匹配的系统组件。如遇兼容问题，请前往[资源下载](/downloads#system-software)获取系统界面与屏幕录制资源。

## 焦点通知破解

通过 HyperCeiler 或内置破解可移除焦点通知白名单限制，使更多应用以焦点通知形式显示。

::: danger 使用前确认
内置破解不支持安全模式，配置或兼容问题可能导致系统界面持续崩溃。请仅在具备恢复系统能力时启用。
:::
